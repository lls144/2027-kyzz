# 新民主主义革命时期四种政权性质

关联 [[考点 38 土地革命战争的发展及其挫折]]。

| 时期 | 政权性质 |
| --- | --- |
| 土地革命战争时期 | 工农民主专政的苏维埃政权 |
| 抗日战争时期 | 抗日民族统一战线性质，一切赞成抗日又赞成民主者的政权 |
| 解放战争时期 | 各个革命阶级的联合专政 |
| 新中国成立初期 | 人民民主专政 |

> [!warning] 关键词定位
> “全国性工农民主政权”对应中华苏维埃共和国；“各革命阶级联合专政”不能提前到土地革命战争时期。（书内页 242-243）
