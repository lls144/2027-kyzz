# 十五大指导思想、基本纲领与新“三步走”

关联 [[考点 90 改革开放和现代化建设的跨世纪发展]]。

1997 年党的十五大：

1. 把邓小平理论确立为党的指导思想并写入党章。
2. 提出社会主义初级阶段基本纲领。
3. 部署跨世纪发展，对所有制结构、公有制实现形式、依法治国和文化建设提出新论断。
4. 对第三步战略目标进一步规划，提出新的“三步走”战略。（书内页 280）
