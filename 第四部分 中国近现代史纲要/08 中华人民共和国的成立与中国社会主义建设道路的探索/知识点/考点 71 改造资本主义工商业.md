# 考点 71 改造资本主义工商业

回到 [[08 第八章 中华人民共和国的成立与中国社会主义建设道路的探索]]。

党用和平方法，经过国家资本主义把民族资本主义工商业改为社会主义性质企业，并对民族资产阶级实行赎买。国家资本主义由加工订货、经销代销等初级形式发展到公私合营高级形式，最终通过全行业公私合营基本完成改造。（书内页 269）
