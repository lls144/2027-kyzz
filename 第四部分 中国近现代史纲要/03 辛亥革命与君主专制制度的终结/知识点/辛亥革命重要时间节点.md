# 辛亥革命重要时间节点

关联 [[考点 21 辛亥革命的爆发与清王朝覆灭]]。

| 时间 | 事件 | 定位 |
| --- | --- | --- |
| 1894-11 | 兴中会成立 | 第一个革命团体 |
| 1905-08-20 | 中国同盟会成立 | 第一个全国性资产阶级革命政党 |
| 1911-04-27 | 广州起义 | 同盟会起义中影响最大，史称黄花岗起义 |
| 1911-05 | 保路风潮 | 四川最为强烈 |
| 1911-10-10 | 武昌起义 | 拉开中国完全意义上的近代民族民主革命序幕 |
| 1912-01-01 | 中华民国临时政府成立 | 孙中山在南京就任临时大总统 |
| 1912-02-12 | 清帝退位 | 封建君主专制制度覆灭 |
| 1912-03 | 《中华民国临时约法》颁布 | 第一部具有资产阶级共和国宪法性质的法典 |
| 1912-03-10 | 袁世凯在北京就任临时大总统 | 革命果实被窃取 |
