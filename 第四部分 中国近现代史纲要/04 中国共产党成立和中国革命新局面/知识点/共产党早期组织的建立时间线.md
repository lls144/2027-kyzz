# 共产党早期组织的建立时间线

关联 [[考点 30 马克思主义与中国工人运动的结合]]。

| 时间 | 事件与定位 |
| --- | --- |
| 1920-02 | “南陈北李，相约建党” |
| 1920-03 | 李大钊在北大组织马克思学说研究会，中国最早学习研究马克思主义的团体 |
| 1920-08 | 上海共产党早期组织在《新青年》编辑部成立，陈独秀任书记；最早的工人阶级政党组织、发起组织和联络中心 |
| 1920-10 | 李大钊等在北京成立早期组织，11 月定名中国共产党北京支部，李大钊任书记 |
| 1920 秋—1921 春 | 武汉、长沙、济南、广州及日本、法国等建立早期组织 |

> [!warning] “最早”辨析
> 马克思学说研究会是最早学习研究马克思主义的团体；上海共产党早期组织是工人阶级政党最早组织。（书内页 232-233）
