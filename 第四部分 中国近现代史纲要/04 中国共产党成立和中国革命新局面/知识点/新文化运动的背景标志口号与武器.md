# 新文化运动的背景标志口号与武器

关联 [[考点 26 新文化运动与思想解放的潮流]]。

| 维度 | 内容 |
| --- | --- |
| 背景 | 辛亥革命失败、北洋军阀统治；先进知识分子认为“根本之救亡”须改造国民性 |
| 开始标志 | 1915 年 9 月陈独秀在上海创办《青年杂志》，后改名《新青年》 |
| 主要阵地 | 《新青年》和北京大学 |
| 基本口号 | 民主与科学，即“德先生”和“赛先生” |
| 主要武器 | 进化论观点和个性解放思想 |
| 主要内容 | 新道德反对旧道德、新文学反对旧文学、白话文反对文言文；批判孔学 |

> [!warning] 内涵辨析
> 当时“民主”既指资产阶级民主主义制度，也指资产阶级民主主义思想；“科学”狭义指自然科学，广义指社会科学。（书内页 229）
