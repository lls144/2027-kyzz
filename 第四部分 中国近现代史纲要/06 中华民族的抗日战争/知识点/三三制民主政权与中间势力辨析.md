# 三三制民主政权与中间势力辨析

关联 [[考点 49 抗日民主根据地的建设]]。

| 范畴 | 构成 |
| --- | --- |
| “三三制”工作人员 | 共产党员、党外进步人士、中间派各 1/3 |
| 代表阶层 | 共产党员代表工农；党外进步人士代表小资产阶级；中间派代表民族资产阶级和开明绅士 |
| 策略总方针中的中间势力 | 民族资产阶级、开明绅士、地方实力派 |

> [!warning] 易混辨析
> “三三制”中间派不含地方实力派；“三三制”也不是共产党、国民党、民主党派各三分之一。（书内页 251、256）
