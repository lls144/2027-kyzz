# 延安整风的内容意义与历史决议

关联 [[考点 51 中国共产党的自身建设]]。

| 内容 | 目标 |
| --- | --- |
| 反对主观主义 | 整顿学风，最主要任务 |
| 反对宗派主义 | 整顿党风 |
| 反对党八股 | 整顿文风 |

主观主义表现为教条主义、经验主义，是“左”右倾错误思想根源。整风是马克思主义思想教育和思想解放运动，使实事求是思想路线在全党确立。（书内页 253）

1944—1945 年六届七中全会原则通过《关于若干历史问题的决议》，总结六届四中全会至遵义会议前历史，使认识一致、增强团结、为七大准备，整风结束。（书内页 253）
