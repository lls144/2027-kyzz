# 相对过剩人口

回到 [[考点 71 资本积累]]。


## 形成机制

资本追逐剩余价值 → 技术进步和积累加速 → 资本有机构成提高 → 可变资本相对减少 → 资本对劳动力需求相对下降 → 相对过剩人口。

“相对”指劳动力供给超过资本价值增殖的需要，并非社会生产绝对不需要这些劳动者。基本形式有流动、潜在、停滞三种。

经常性失业是资本主义痼疾，政府干预只能缓解，无法在资本主义制度内彻底消除。
