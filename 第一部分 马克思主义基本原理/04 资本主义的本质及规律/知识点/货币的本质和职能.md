# 货币的本质和职能

回到 [[考点 64 价值形式的发展与货币]]。


## 本质

货币是固定充当一般等价物的商品，是商品经济内在矛盾发展的产物，本质上体现社会关系。

## 五种职能

| 职能 | 识别线索 |
| --- | --- |
| 价值尺度 | 标价，观念货币 |
| 流通手段 | 一手交钱一手交货，现实货币 |
| 贮藏手段 | 退出流通，足值金属货币 |
| 支付手段 | 赊购、债务、租金等延期支付 |
| 世界货币 | 各职能在世界范围应用 |

价值尺度和流通手段是最基本职能。货币促进交换，但没有消灭商品矛盾，反而可能扩大矛盾。
