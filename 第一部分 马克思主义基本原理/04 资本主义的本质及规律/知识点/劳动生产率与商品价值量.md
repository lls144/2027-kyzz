# 劳动生产率与商品价值量

回到 [[考点 63 商品价值量的决定]]。


## 关系表

| 劳动生产率提高时 | 变化 |
| --- | --- |
| 单位时间商品数量/使用价值量 | 增加 |
| 单位时间价值总量 | 不变 |
| 单位商品社会必要劳动时间 | 减少 |
| 单位商品价值量 | 减少 |

价值量与社会必要劳动时间成正比、与社会劳动生产率成反比。同一劳动在同样时间内提供的价值量不因生产率变化而变。

> [!warning] 易错点
> 部门劳动生产率影响单位商品社会价值；个别企业生产率高于平均水平，首先形成个别价值低于社会价值的超额剩余价值。
