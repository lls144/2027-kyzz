# 当代资本主义变化的新特征

回到 [[考点 82 当代资本主义变化的新特征]]。


## 四项特征

1. 科技创新改变生产方式：产业结构、生产组织和劳动形式、新经济形态。
2. 国际金融垄断资本主义影响突出：寡头化、国际化、虚拟化和产业空心化。
3. 社会阶级层级复杂、多样。
4. 发达国家推行霸权主义、强权政治。

最突出、最鲜明、最主要的特征是**国际金融资本的垄断**。

新变化拓展发展空间，也放大系统性危机；没有改变资本主义经济基础和利润最大化本性。
