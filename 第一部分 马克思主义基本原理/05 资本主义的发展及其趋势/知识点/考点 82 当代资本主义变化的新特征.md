# 考点 82 当代资本主义变化的新特征

回到 [[05 第五章 资本主义的发展及其趋势|第五章 资本主义的发展及其趋势]]。


## 四项新特征

1. 科技创新加速生产方式变化：产业结构调整，生产组织和劳动形式变化，新经济形态出现。
2. 国际金融垄断资本主义影响日益显现：金融垄断寡头化、国际化，经济虚拟化和产业空心化。
3. 社会阶级层级结构复杂、多样。
4. 发达资本主义国家凭借经济、科技、文化优势推行霸权主义和强权政治。

**国际金融资本的垄断是当代资本主义最突出、最鲜明、最主要的特征。**

这些变化没有改变资本主义经济基础和利润最大化本性，反而放大系统性危机和全球性矛盾。
