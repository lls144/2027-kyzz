# 资本主义被社会主义取代的必然性

回到 [[考点 84 资本主义的历史地位和发展趋势]]。


## 四条依据

1. 资本主义基本矛盾包含现代冲突萌芽，只有社会主义才能根本解决。
2. 资本积累提高生产社会化和集中程度，为否定资本主义准备物质条件。
3. 国家垄断资本主义是资本社会化更高形式，是社会主义的物质准备和前阶。
4. 资产阶级与无产阶级矛盾及斗争推动制度更替。

社会主义取代资本主义是历史必然趋势，但不是资本主义短期自动消亡。
