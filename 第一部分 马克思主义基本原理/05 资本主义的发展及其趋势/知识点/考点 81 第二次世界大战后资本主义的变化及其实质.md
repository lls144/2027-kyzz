# 考点 81 第二次世界大战后资本主义的变化及其实质

回到 [[05 第五章 资本主义的发展及其趋势|第五章 资本主义的发展及其趋势]]。


## 五类变化

1. 所有制：私人资本 → 私人股份资本 → 国家资本与法人资本，法人资本成为主导。
2. 劳资和分配：职工参与决策、终身雇佣、持股及社会福利等缓和矛盾。
3. 阶级阶层：资本家成为食利者，高级职业经理实际控制大公司，知识服务劳动者增加。
4. 调节和危机：国家干预与市场调节关系变化，危机金融化、债务化、结构化。
5. 政治制度：权利扩大、法治加强、改良主义政党影响增加。

## 原因和实质

根本推动力是科技革命和生产力发展，另有工人斗争、社会主义制度影响和改良主义改革。变化是一般社会规律和资本主义经济规律作用的结果，仅发生在资本主义基本框架内，没有改变生产关系根本性质、制度本质和基本矛盾。
