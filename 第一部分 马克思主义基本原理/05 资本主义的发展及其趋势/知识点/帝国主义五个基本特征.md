# 帝国主义五个基本特征

回到 [[考点 79 垄断资本主义的发展]]。


## 五个特征

1. 垄断组织在经济生活中起决定作用。
2. 金融资本基础上形成金融寡头统治。
3. 资本输出具有特别重要意义。
4. 瓜分世界的资本家国际垄断同盟形成。
5. 最大资本主义大国把世界领土瓜分完毕。

这些特征集中体现帝国主义实质：垄断资本凭借垄断地位获取高额垄断利润。
