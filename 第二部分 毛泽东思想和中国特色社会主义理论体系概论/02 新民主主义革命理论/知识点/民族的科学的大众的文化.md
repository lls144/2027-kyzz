# 民族的科学的大众的文化

回到 [[新民主主义文化纲领]]。

| 特征 | 核心含义 |
| --- | --- |
| 民族的 | 内容反帝、维护民族尊严独立；形式有民族风格和中国气派，同时吸收外国进步文化 |
| 科学的 | 反对封建思想和迷信，坚持实事求是、客观真理、理论联系实际 |
| 大众的 | 服务工人阶级和劳动群众，文化普及与提高统一，因而也是民主的 |

> [!warning] 易错点
> 民族性不等于排斥外国进步文化；大众性不等于只讲普及而不讲提高。
