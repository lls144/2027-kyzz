# 不同历史阶段的革命主要对象

回到 [[新民主主义革命的对象]]。

| 历史阶段 | 主要革命对象 |
| --- | --- |
| 国共合作的大革命时期 | 帝国主义支持下的北洋军阀 |
| 土地革命战争时期 | 国民党新军阀 |
| 抗日战争时期 | 日本帝国主义 |
| 解放战争时期 | 美帝国主义支持下的国民党反动派 |

> [!warning] 判断方法
> 总路线规定总体对象，具体阶段要根据当时最突出的主要矛盾确定主要打击对象。
