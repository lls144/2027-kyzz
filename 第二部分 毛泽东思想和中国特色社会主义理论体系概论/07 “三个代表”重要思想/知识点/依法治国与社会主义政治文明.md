# 依法治国与社会主义政治文明

回到 [[考点 27 “三个代表”重要思想的核心观点与主要内容]]。

建设社会主义政治文明是“三个代表”重要思想的主要内容之一。1999 年，“实行依法治国，建设社会主义法治国家”正式入宪。（书内页 128）

党的十五大报告指出，依法治国是：（书内页 129）

1. 党领导人民治理国家的基本方略；
2. 发展社会主义市场经济的客观需要；
3. 社会文明进步的重要标志；
4. 国家长治久安的重要保障。
