# 农业合作化的三种组织形式

回到 [[农业社会主义改造道路]]。

| 组织形式 | 性质 |
| --- | --- |
| 互助组 | 社会主义萌芽性质 |
| 初级农业生产合作社 | 半社会主义性质 |
| 高级农业生产合作社 | 完全社会主义性质 |

> [!tip] 章节练习
> 具有完全社会主义性质的是高级农业生产合作社，不是互助组或初级合作社。
