# 资本主义工商业和平赎买的现实可能性

回到 [[资本主义工商业的和平赎买]]。

1. 民族资产阶级具有两面性：既剥削工人获取利润，又拥护党的领导、拥护宪法并愿意接受社会主义改造。
2. 中国共产党同民族资产阶级长期保持统一战线关系。
3. 已有人民民主专政国家政权和掌握国家经济命脉的强大社会主义国营经济。
4. 国家实行粮食和工业原料统购统销，资本主义企业中工人群众能够监督资本家。
