# 新民主主义社会的五种经济成分

回到 [[考点 11 从新民主主义到社会主义的转变]]。

1. 社会主义性质的国营经济。
2. 半社会主义性质的合作社经济。
3. 农民和手工业者的个体经济。
4. 私人资本主义经济。
5. 国家资本主义经济。

其中主要经济成分有三种：社会主义经济、个体经济、资本主义经济。国营经济居领导地位，个体经济占绝对优势并处于“十字路口”。过渡性质的经济成分是合作社经济和国家资本主义经济。

> [!tip] 2017 年单选题
> 个体经济向社会主义集体经济过渡的形式是合作社经济。
