# 考点 81 完善社会治理体系

回到 [[11 第十一章 以保障和改善民生为重点加强社会建设]]。

社会治理体系是社会治理的基础和提高治理效能的保障。要完善党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑的体系；共建是基础，共治是关键，共享是目标。（书内页 182）

> [!warning] 易混辨析
> 共建是基础、共治是关键、共享是目标；制度是保障，方式方法是重要内容。（书内页 182）
