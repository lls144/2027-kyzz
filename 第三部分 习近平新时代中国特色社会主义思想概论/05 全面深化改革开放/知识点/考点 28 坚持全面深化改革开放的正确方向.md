# 考点 28 坚持全面深化改革开放的正确方向

回到 [[05 第五章 全面深化改革开放]]。

正确方向首先是坚持和改善党的全面领导、坚持和完善中国特色社会主义制度，并以此作为改什么、怎样改的根本标准。（书内页 150）

坚持以人民为中心，促进公平正义、增进人民福祉，是进一步全面深化改革的出发点和落脚点。（书内页 150）

三个进一步解放既是改革目的又是条件：进一步解放思想；进一步解放和发展社会生产力（鲜明特征和首要任务）；进一步解放和增强社会活力（关键所在）。（书内页 150）
